# Security Policy

To report a security vulnerability, please do so using [Private vulnerability reporting](https://github.com/PrinsFrank/standards/security/advisories/new)

## Supported versions

Security updates are provided for recent major versions that still represent significant downloads.

As a guideline, as long as [more than 5% of downloads](https://packagist.org/packages/prinsfrank/standards/stats) are for a major version it is considered supported.

In practice that means that currently v2, v3 and v4 get security updates. Supported versions are reviewed periodically and will be updated here as usage patterns change.
